Artigo/Código Base

O que estou interessado em pesquisar?

Existem artigos utilizando Deep Learning nesse problema?

Se não, muito cuidado! Talvez Deep Learning não seja adequado para o problema
proposto.

Você tem infraestrutura para suportar as exigências de hardware para trabalhar
com esse artigo/código?

Os artigos que encontrei são recentes? Possuem código-fonte recente? Está no
GitHub? É a implementação original do autor do artigo? Está em PyTorch ou
TensorFlow? Em qual versão? Existem implementações alternativas?

Inovação/Estudo

Qual evolução/inovação será proposta? O que se está propondo é algo
não conhecido? Pretende fazer um estudo comparativo?

Há tempo hábil para adaptar o código base, fazer os experimentos,
ANÁLISES quantitativas/qualitativas, e escrever o artigo?

Quais alternativas de evolução você pretende testar? Por que você supõe
que irá funcionar bem? Está sendo aplicado em outros casos que não o
artigo/código base?

Você entende e está confortável em alterar o código base e implementar as
alterações propostas? Existe implementação do que você está pensando
em fazer em códigos de outros artigos?

Datasets e Métricas

Quantos datasets você pretende usar? Você tem acesso aos
datasets? Eles são suficientemente diferentes? Possuem graus de
dificuldade distintas? Para efeito de comparação, esses datasets são
usados no artigo base e outros relacionados ao mesmo problema?

Que métricas você pretende utilizar? Você tem código pronto para
calculá-las? Para efeito de comparação, essas métricas são usados
no artigo base e outros relacionados ao mesmo problema? Elas são
relevantes para o problema considerado?

Dica: Salve as métricas (ao longo das épocas) do experimento em
arquivos “csv” para depois poder estudá-las no Pandas, Seaborn, etc.
