    self.edges[u][v] = min(1.0, self.edges[u][v] + weight)

A topologia inicial é uma cadeia linear temporal. Cada novo turno $t$ é acoplado bidirecionalmente ao turno $t-1$ com peso $W_{t, t-1} = 0.5$. O teto de saturação da sinapse é estritamente limitado em $1.0$.

        for target_id, weight in neighbors.items():

Seja $A_i$ a ativação base do nó $i$. Se $A_i > \theta$, ele propaga energia para todo vizinho $j$ com aresta $W_{ij}$. O incremento é $\Delta A_j = A_i \cdot W_{ij} \cdot \alpha$. 🔬 VISÃO TÉCNICA Hebbian Co-activation Update 
# hebbian_memory.py
def reinforce_memory_cluster(self, node_ids):
    """
    Reforça conexões entre todos os pares resgatados juntos.
    """
    if len(node_ids) < 2: return
    for i in range(len(node_ids)):
        for j in range(i + 1, len(node_ids)):
            u, v = node_ids[i], node_ids[j]
            # Incrementa o peso sináptico com taxa de aprendizado:
            self.add_edge(u, v, weight=self.learning_rate) # lr = 0.02

A cada consulta, os $K$ nós selecionados sofrem atualização de co-ativação completa: para cada par $(u, v)$, $W_{uv} \leftarrow \min(1.0, W_{uv} + \eta)$, onde $\eta = 0.02$. O grafo aprende dinamicamente a associar memórias correlatas através do próprio ato de responder perguntas.
